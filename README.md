# 滚动霓虹 · Rolling Neon

一个用 **Three.js** 开发的 3D 网页跑酷小游戏，玩法类似《滚动天空》(Rolling Sky)。

## 🎮 玩法

- 小球在悬空的霓虹赛道上自动向前飞驰，速度会越来越快
- **收集宝石**加分，**躲开红色障碍**，**千万别掉进虚空**
- 赛道上会随机出现**绿色弹板**，踩上去会被高高弹起，飞跃长段缺口
- 跑到赛道尽头（600 米）即达成 **100% 完美通关**，最佳进度本地保存

## ⌨️ 操作

| 平台 | 移动 | 跳跃 |
|------|------|------|
| 电脑 | `←` `→` 或 `A` `D` | `空格` / `↑` / `W`（支持二段跳） |
| 手机 | 按住屏幕左右拖动 | 轻点一下屏幕 |

`Enter` / `空格` 开始或重新开始；右下角按钮可开关音效。

## ✨ 技术要点

- **Three.js r160** 渲染，`UnrealBloomPass` 辉光后处理 + ACES 色调映射
- **程序化关卡生成**：安全路径采用随机游走算法，保证每局永远存在可行路线；砖块、缺口、障碍、宝石、弹板按进度动态调整密度
- **对象池**：砖块 / 宝石 / 障碍 / 粒子全部复用，长时间运行不掉帧
- **WebAudio 合成音效**：收集、起跳、弹射、坠落、通关音乐全部由振荡器实时合成，零音频文件
- 宽容碰撞判定（边缘 3×3 采样），移动端 `pointer events` 统一处理拖动与轻点

## 🚀 运行方式

Three.js 已内置在 `lib/` 目录中，**无需联网、不依赖任何 CDN**。

方式一：本地起一个静态服务器后访问（推荐，手机也可局域网访问）：

```bash
# Python
python -m http.server 8080
# 或 Node
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

方式二：直接访问在线版：<https://liu123915.github.io/rolling-neon/>
