# 滚动霓虹 · Rolling Neon（ip-02-three-game）

《互动编程》作业二 · 互动艺术与电子媒介（Three.js） · 刘晓茹 · 数字媒体艺术

一个用 **Three.js** 开发的 3D 网页跑酷小游戏，玩法类似《滚动天空》(Rolling Sky)。打开网址就能玩，不需要安装任何东西。

在线试玩：<https://liu123915.github.io/ip-02-three-game/>

## 🎮 游戏规则

- 小球在悬空的霓虹赛道上自动向前飞驰，速度随进度越来越快
- **收集宝石**加分，**躲开红色障碍**，**掉进虚空即失败**
- 赛道上随机出现**绿色弹板**，踩上去会被高高弹起，可飞跃长段缺口
- 跑到赛道尽头（600 米）即 **通关**
- 失败 / 通关后可随时**再来一局**，最佳进度保存在本地

## ⌨️ 操作

| 平台 | 移动 | 跳跃 | 视角 |
|------|------|------|------|
| 电脑 | `←` `→` 或 `A` `D` | `空格` / `↑` / `W`（支持二段跳） | **按住鼠标拖动 = 绕小球旋转视角**，`C` 复位 |
| 手机 | 按住屏幕左右拖动 | 轻点一下屏幕 | 暂由系统自动跟随 |

`Enter` / `空格` 开始，`R` 随时重开一局；右下角按钮可开关音效。

## ✨ 技术要点

- **Three.js r160** 渲染，`UnrealBloomPass` 辉光后处理 + ACES 色调映射
- **可环绕相机**：鼠标拖拽改变水平偏航与俯仰角（带限位与阻尼），松手不弹回，按 `C` 归位
- **程序化关卡生成**：安全路径采用随机游走算法，保证每局永远存在可行路线；砖块、缺口、障碍、宝石、弹板按进度动态调整密度
- **对象池**：砖块 / 宝石 / 障碍 / 粒子全部复用，长时间运行不掉帧
- **WebAudio 合成音效**：收集、起跳、弹射、坠落、通关音乐全部由振荡器实时合成，零音频文件
- 宽容碰撞判定（边缘 3×3 采样），移动端 `pointer events` 统一处理拖动与轻点
- 小球使用 PBR 金属材质 + 虹彩（iridescence）+ 程序化蜂窝凹凸贴图 + 菲涅尔边缘光

## 🚀 运行方式

Three.js 已内置在 `lib/` 目录中，**无需联网、不依赖任何 CDN**（国内网络也能秒开）。

方式一：直接访问在线版：<https://liu123915.github.io/ip-02-three-game/>

方式二：本地起一个静态服务器后访问（手机也可局域网访问）：

```bash
# Python
python -m http.server 8080
# 或 Node
npx serve .
```

然后浏览器访问 `http://localhost:8080`。
